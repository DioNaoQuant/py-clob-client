### 安装

安装dev分支上的自定义py_clob_client包，以解决源包的若干bug

```bash
pip install git+https://github.com/Dionysos-o/py-clob-client.git@dev#egg=py_clob_client
```
推荐安装在 Python 3.12环境下.
